# CT-Task4-Detector

This repo deals with the physically-grounded simulation of multi-row, energy-integrating CT detectors and the processing of incident X-ray signals into digital sinograms.

# Phase 1: Physically-Grounded CT Detector Pipeline

## 1. Module Overview

This Phase 1 implementation models a complete energy-integrating X-ray CT detector signal chain. It ingests incident X-ray photon fluences (such as those generated by a tissue interaction model) and applies realistic material physics and hardware imperfections. The pipeline does **not** assume an ideal photon-counting detector. Instead, it processes the incident fluence through a cascaded linear-systems noise model.

The system begins by initializing the detector geometry and physics models from a configuration dictionary. It calculates X-ray absorption efficiency (quantum efficiency), applies Poisson noise, models the secondary quantum sink (Swank factor), and applies spatial cross-talk (optical/charge spread blur). Additive Gaussian electronic read noise is introduced, followed by a hardware imperfection layer that applies a static dead-pixel map, fixed-pattern dark offsets, and pixel-to-pixel gain non-uniformity.

Finally, the simulated electron-domain signals can be digitized into ADC counts, reshaped into flattened 1D arrays (matching upstream tissue interaction outputs), and reconstructed into cross-sectional images using Filtered Back-Projection (FBP).

# 3. End-to-End Pipeline

The current execution flow is:

```text
Detector Configuration
        │
        ▼
 ct_detector_simulator.py
        │
        ├── Build Material Model (QE, Swank)
        │
        ├── Build Electronic Noise Model
        │
        ├── Generate Defect Maps (Dead pixels, Gain)
        │
        ▼
 For every CT view (ct_sinogram_simulation.py)
        │
        ├── Receive incident photon fluence (from Phantom)
        │
        ├── Calculate ideal signal (eta * g)
        │
        ├── Inject Quantum + Swank Noise (Poisson/Gamma)
        │
        ├── Apply Optical/Charge Spread (Gaussian Blur MTF)
        │
        ├── Inject Electronic Read Noise (Gaussian)
        │
        ├── Apply hardware imperfections (Gain, Offset, Dead Pixels)
        │
        ├── Flatten to 1D detector signal array
        │
        ├── (Optional) Correct known bad channels via interpolation
        │
        └── Append to all_detector_signals
        │
        ▼
   Filtered Back-Projection (FBP) Reconstruction
        │
        ▼
 detector_sim_outputs/

```

# 5. Module Documentation

## 5.1 `ct_detector_simulator.py`

### Purpose

This is the core physics library. It houses the data classes and pipelines necessary to convert a theoretical X-ray fluence into a realistic, noisy detector readout.

### Classes and Functions

#### `MaterialModel`, `ElectronicNoiseModel`, `ImperfectionModel`

Dataclasses that define the physical constants (e.g., `swank_factor`, `light_yield_photons_per_kev`), readout constraints (e.g., `full_well_capacity_e`, `electronic_noise_std_e`), and defect severities.

#### `CTDetectorSimulator`

The main class that initializes the static defect maps (`_build_defect_maps`) based on a provided RNG seed, ensuring the detector behaves like a consistent physical unit.

#### `CTDetectorSimulator.simulate_projection(incident_photon_image)`

Runs the full detector physics pipeline on an incident-photon-fluence image.

Major operations:

1. Calculates ideal noiseless signal.
2. Generates absorbed counts via Poisson distribution.
3. Applies Swank factor variance via Gamma distribution.
4. Applies separable Gaussian blur for optical cross-talk.
5. Adds Gaussian electronic noise.
6. Applies gain, offset, and dead-pixel maps.
7. Returns a dictionary of intermediate and final signal states.

#### `CTDetectorSimulator.dqe0(q)`, `mtf(f)`

Calculates the zero-frequency Detective Quantum Efficiency based on exposure ($q$) and the Modulation Transfer Function.

# 6. `run_detector_demo.py`

## Purpose

A demonstration script to evaluate baseline detector metrics independent of complex multi-view geometry.

The main workflow:

1. Instantiates a `CTDetectorSimulator` with a GOS scintillator reference config.
2. Generates an MTF and DQE characterization figure (`detector_characterization.png`), comparing reference electronics to a degraded electronics variant to visualize the electronic noise floor.
3. Simulates a single projection through a synthetic water-cylinder phantom (`phantom_projection.png`) at normal and low doses to demonstrate quantum noise scaling and uncorrected dead-pixel artifacts.

# 7. `ct_sinogram_simulation.py`

## Purpose

Extends the detector physics to a multi-view acquisition scenario, generates a random tissue phantom, produces a simulated sinogram, and reconstructs the image.

### `RandomTissuePhantom`

Procedurally generates an elliptical background body with a random number of non-overlapping tissue inclusions (e.g., bone, lung, iodine contrast).

### `line_integral(theta_rad, u_mm)`

Analytically forward-projects the random phantom using a parallel-beam, ellipse/line intersection algorithm.

### Multi-Angle Acquisition Loop

Loops over 180 or 360 views, computing the line integral, mapping incident fluence, and pushing the data through the `simulate_projection()` pipeline.

Crucially, it formats the output into the flat 1D array required by upstream tissue interaction modules:

```python
detector_signal = signal_image.flatten() 

```

### Bad-Channel Correction & FBP

Demonstrates standard pre-reconstruction calibration by interpolating missing data over known dead columns, preventing catastrophic ring artifacts in the final `skimage.transform.iradon` reconstruction.

# 10. Validation Approach

The current implementation can be validated at multiple stages.

## Physics Validation

Check:

* **MTF Curve:** Should drop from 1.0 at DC frequency to a lower value approaching Nyquist, following the sinc/Gaussian convolution.
* **DQE:** The quantum-limited plateau should equal $\eta \times A_{swank}$. Low exposures should drop sharply (the electronic noise "knee").
* **Noise Budget:** Total RMS noise should follow $\sqrt{\sigma_{quantum}^2 + \sigma_{electronic}^2}$.

## Output Format Validation

Check:

```text
all_detector_signals.shape

```

Expected current structure:

```text
(n_views, 56832)

```

## Reconstruction Validation

Compare the central horizontal profile of the FBP reconstruction against the rasterized ground-truth phantom. Inclusion boundaries and relative attenuation values (e.g., bone vs. lung) should align.

# 11. Current Phase 1 Assumptions and Limitations

The following are part of the **current implementation**:

1. **Energy-integrating model.** Photon-counting spectral binning is not modeled; the signal is a weighted integration of energy deposited.
2. **Effective Energy Approximation.** The material physics currently uses a single CT effective energy (~65 keV) rather than full polyenergetic spectral integration per ray.
3. **Parallel-Beam Approximation.** The current sinogram forward projector simplifies the geometry to a parallel beam for standard `iradon` reconstruction compatibility.
4. **Gaussian Cross-Talk.** Optical spread is modeled as a separable 1D Gaussian blur rather than a precise Monte Carlo scatter kernel.

# 16. Phase 1 Scope

The current Phase 1 implementation focuses on establishing the physical transformation from a pure, mathematical X-ray line-integral into a realistic, noisy, digitized detector readout. It successfully bridges the gap between tissue interaction algorithms and the final raw data structures required for CT image reconstruction.
